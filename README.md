```text
                    ┌───────────────┐
                    │    PROBLEM    │
                    └───────┬───────┘
                            ↓
                    ┌───────────────┐
                    │    THINK      │
                    └───────┬───────┘
                            ↓
                    ┌───────────────┐
                    │    DESIGN     │
                    └───────┬───────┘
                            ↓
                    ┌───────────────┐
                    │     BUILD     │
                    └───────┬───────┘
                            ↓
                    ┌───────────────┐
                    │  TEST / DEBUG │
                    └───────┬───────┘
                            ↓
                    ┌───────────────┐
                    │    IMPROVE    │
                    └───────────────┘
```

</div>

### 💎 Engineering Principles

* 🧠 Understand before implementing
* 🧱 Build reusable components
* 🔷 Prefer type-safe development
* 🧹 Keep code readable
* ♻️ Reduce unnecessary duplication
* ⚡ Think about performance
* 📱 Design responsive interfaces
* 🔐 Consider security
* 🧪 Test assumptions
* 📚 Keep learning
